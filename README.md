# Hermes Eliram — Portfolio

Ingénieur logiciel. Je conçois et livre des produits complets, du premier écran à la production.

Portfolio en ligne : https://hermes-eliram.pages.dev

## Stack

React + Vite + Tailwind CSS + Framer Motion.

Tout le texte vit dans `src/content.js` — c'est le seul fichier à modifier pour mettre à jour bio, projets, offres et avis.

## Développement

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # sortie dans dist/
npm run preview
```

## Structure

- `src/content.js` — tout le contenu éditable
- `src/sections/` — Hero, About, Expertise, Projects, Testimonials, Services (estimateur), Contact
- `src/components/` — Section, Reveal, Stat, ServiceIcon, CodeWindow, Character
- `public/projects/` — visuels des projets

## Déploiement

Cloudflare Pages, déploiement automatique depuis `main`.
